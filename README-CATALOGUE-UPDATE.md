# Catalogue and pricing update

- Start at `index.html`; use the new Browse through the catalogue link in the sticker section.
- Select any number of distinct catalogue designs. Choose a sheet layout (4 × 4 / 16 one-inch, 3 × 4 / 12 two-inch, or 2 × 3 / 6 three-inch) and finish. Complete sheets are added to the bag together; incomplete leftover selections remain saved in the catalogue for the next sheet.

- Crossed out comparison prices appear for standard products. Confirm that every comparison reflects a genuine reference price before publishing promotional claims.

## Owner catalogue page

Open `catalogue-manager.html` to add, edit, hide, restore or delete stickers, replace cropped originals, create a category with **Other**, and add public Instagram posts. With the one-time Vercel setup in `CATALOGUE-MANAGER-SETUP.md`, Save publishes to every visitor through the live API. No code edits are needed for later catalogue updates. Without that setup, the page clearly displays Preview mode and offers a backup export; a local browser draft is not public.

The catalogue has search, category filters, collapsed pack groups, and a roomier gallery. Several original source sheets contain cut artwork; those missing parts cannot be recovered from layout changes. Replace those codes with complete artwork in the manager before relying on them as print-ready individual files.

## Product views and search

Each pack has a laptop view, its complete sheet as frame two, a frame for every original sticker design, and the same quality slide at the end. The separate all-design carousel includes all 158 catalogue entries. The new original cutouts are artwork; the laptop scenes are illustrative product previews.

Open `product-manager.html` for separate Light Box and other-product sections. You can edit names, descriptions, photos, sizes, finishes, prices and availability; create other products; hide or restore existing products; and back up changes. The manager uses the same one-time Vercel setup as the sticker manager in `CATALOGUE-MANAGER-SETUP.md`. After configuration, Save updates the public website for all visitors on refresh. Without it, changes are local drafts only.

The website includes canonical URLs, brand-specific titles and share metadata, Organization/WebSite structured data, robots.txt and a two-page sitemap. Deploy to the canonical domain, verify the domain in Google Search Console, submit the sitemap, and request indexing for the home and catalogue URLs. Use the exact brand name consistently in your Instagram and YouTube profiles and link those profiles back to the domain. Google controls indexing and ranking; first place and virality cannot be guaranteed by website markup.
