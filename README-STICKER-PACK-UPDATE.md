# Sticker pack storefront

Open `index.html` for the store and `catalogue.html` for the A4-printable, coded sticker catalogue. Upload the contents of this folder together, preserving the directory structure. `sticker-catalogue.csv` is an internal code index.

The site contains 11 preset category packs and 146 uniquely coded sticker designs. Every preset sheet of 6, 12, or 16 costs ₹99 regular or ₹199 holographic. A custom mix costs ₹129 regular or ₹229 holographic and requires exactly 6, 12, or 16 different catalogue codes. Pack slides have a laptop preview and a catalogue link.

The video in the Instagram section is locally hosted. The “View latest reels” button opens the current Instagram Reels tab; the static site does not automatically import new posts. Cart, PDF, and the admin dashboard remain browser-local as in the source website. Orders are completed by sharing the order details through WhatsApp; no automatic order email is sent by this ZIP.
