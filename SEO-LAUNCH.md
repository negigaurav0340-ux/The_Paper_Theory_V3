# Search launch steps for The Paper Theory

This build has an exact brand name on the home page, WebSite and Organization structured data, canonical URLs, consistent social profile links, robots.txt, descriptive internal links and a sitemap containing the home, catalogue, sticker packs, Light Boxes and About pages. The category and About pages contain readable product information in the initial HTML, visible breadcrumbs and BreadcrumbList markup. Descriptions avoid prices that a manager can later change.

1. Deploy the contents of this ZIP to the actual `thepapertheory.in` domain. Check `https://thepapertheory.in/`, `/catalogue.html`, `/sticker-packs.html`, `/light-boxes.html`, `/about.html`, `/robots.txt` and `/sitemap.xml` directly. Make sure HTTPS and the canonical host work consistently.
2. Verify the domain property in Google Search Console using the DNS record Google provides. Submit `https://thepapertheory.in/sitemap.xml`, inspect each important URL, and request indexing after the pages are live.
3. In Search Console, monitor the query **The Paper Theory**, branded impressions, indexing, and page experience. Fix indexed page issues before adding more content. The metadata in the ZIP cannot submit the site to Google by itself.
4. Use the exact business name and domain on Instagram, YouTube and other real brand profiles. Link the profiles back to the website. Publish useful original product demonstrations and accurate photos, rather than repeated keyword lists.
5. For product search visibility, build dedicated product pages with accurate current prices, availability and return information before adding Product/Offer structured data or a Merchant Center feed. The owner manager can change prices, so static offer markup could become stale; this build deliberately avoids misleading price-rich results.

Google chooses ranking and the displayed site name automatically. First position for a brand search cannot be guaranteed. Search Console and live deployment access are needed to verify the result.
